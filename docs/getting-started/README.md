# Getting Started 🚀

Welcome to Nexa Pay! This guide will help you get up and running.

## What is Nexa Pay?

Nexa Pay is a comprehensive financial platform that provides:
- Secure payment processing
- Card management and control
- Transaction tracking and reporting
- Multi-currency support
- API access for integration

## For Users

1. Download the Nexa Pay app (iOS/Android)
2. Create an account
3. Verify your identity
4. Activate your Nexa Card
5. Start making payments

## For Developers

1. Create a developer account
2. Generate API credentials
3. Read the [API Documentation](../api/README.md)
4. Integrate using our SDKs
5. Test in sandbox environment

## Key Concepts

### Authentication
All API requests require authentication using JWT tokens.

### Payment Processing
Payments are processed securely through our PCI-DSS compliant infrastructure.

### Webhooks
Receive real-time notifications for payment events.
