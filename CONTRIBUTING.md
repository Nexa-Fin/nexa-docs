# Contributing to Nexa Documentation

We welcome documentation contributions!

## How to Contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b docs/your-topic`
3. Make documentation changes
4. Commit: `git commit -m 'docs: add your topic'`
5. Push: `git push origin docs/your-topic`
6. Open a Pull Request

## Documentation Standards

- Use clear, concise language
- Include code examples
- Add table of contents for long documents
- Include relevant links
- Keep formatting consistent
- Use Markdown for all documents

## Structure

Place documentation in the appropriate directory:
- `docs/getting-started/` - Beginner guides
- `docs/api/` - API documentation
- `docs/architecture/` - System design
- `docs/deployment/` - Deployment guides
- `examples/` - Code examples

## Review Process

- All PRs require at least one review
- Documentation must be accurate and up-to-date
- Examples must be tested
- Links must be valid
